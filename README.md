# 紫微・八字・星座・占卜

一個純前端、單一 HTML 檔的命理工具：紫微斗數排盤（含古派格局與流日四化）、八字、西洋星盤、三合一整合分析、每日盤勢，以及易經（周易原文、梅花易數、六爻納甲）與塔羅占卜。

👉 線上使用：https://pickupstone.github.io/ZiWei_Stone/

## 隱私

- 沒有伺服器、沒有資料庫，不載入任何第三方程式。
- 只用 GoatCounter 圖片計數統計瀏覽與功能使用次數（不使用 Cookie、不送出任何輸入內容）。
- 輸入的生辰與問題只在使用者自己的瀏覽器裡計算，不上傳、不儲存。
- 頁面以 Content-Security-Policy 禁止對外連線，僅允許 ziweistone.goatcounter.com 的計數圖片。

## 使用方式

直接開啟網址，或下載 `index.html` 用瀏覽器打開（可離線使用）。
